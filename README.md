# 車のコーティング・洗車 見積もりデモ

## サービス概要

車両サイズや施工メニュー、車両の状態などを選択することで、コーティング・洗車サービスの概算料金を自動計算できるWeb見積もりツールです。

お客様自身で必要なサービスを選択し、問い合わせ前に料金の目安を確認できます。

## デモサイト

https://luno-creative.github.io/car-coating-estimate-demo/

## 主な機能

- 車両サイズの選択
- 洗車メニューの選択
- ボディコーティングメニューの選択
- 車両のボディ状態に応じた追加料金
- 車内清掃オプション
- ホイール洗浄オプション
- 選択内容に応じた料金の自動計算
- 見積もり内容の確認

## 使用技術

- HTML
- CSS
- JavaScript

## 操作方法

1. デモサイトにアクセス
2. 車両サイズを選択
3. 希望する洗車・コーティングメニューを選択
4. 車両の状態や追加オプションを選択
5. 自動計算された概算料金を確認

## 制作目的

自動車関連事業者向けのWeb見積もりシステムのデモとして制作しました。

料金体系が複雑になりやすいコーティング・洗車サービスにおいて、料金計算の自動化と問い合わせ前の不安解消を目的としています。

## 注意事項

本サイトは営業・提案用のデモサイトです。

表示される料金やサービス内容はサンプルであり、実際の店舗・事業者の料金体系を示すものではありません。
